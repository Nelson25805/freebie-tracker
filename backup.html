What's actually in a backup?

A backup is a small file — just the list of game IDs you've marked, plus when it was made. Nothing sensitive, no account info, because there's no account: 

{
  "type": "fgt_collected_backup",
  "version": 1,
  "exportedAt": "2026-08-30T12:00:00.000Z",
  "collected": [
    "8401414902e84f2cb9afa9142f051d32",
    "psplus-signalis",
    "steam-3716"
  ]
}

A backup code is exactly this, just as plain text instead of a downloaded file — handy for pasting into a notes app or password manager instead of juggling a Downloads folder.

Common questions

Do I need an account? No — there isn't one. Everything lives in your browser's local storage, which is why backups are the only way to move marks between devices or browsers.

Will I lose my marks if I clear my browser data? Yes, unless you've backed up first — clearing site data, using a private/incognito window, or reinstalling your browser all wipe local storage.

What happens if I import the same backup twice? Nothing changes — merging is safe to repeat, since it just adds whatever's in the file to what's already here.

Backups never leave your device unless you save or send the file yourself — nothing is uploaded anywhere by this page.
